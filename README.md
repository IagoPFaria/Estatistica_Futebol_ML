# Estatística Futebol ML

Projeto de estudo e desenvolvimento de um sistema de Machine Learning aplicado a estatísticas de futebol.

## Objetivo

Construir uma pipeline capaz de coletar, organizar e analisar dados de partidas de futebol para gerar previsões probabilísticas.

## Status

Em desenvolvimento.
